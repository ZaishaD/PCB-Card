PCB Card 
Overview:
This project is a custom-designed PCB business card created using EasyEDA. Instead of a traditional paper card, this design uses a printed circuit board to showcase creativity, basic electronics knowledge, and design skills. The card includes decorative traces, text, and optional LED features to make it interactive and visually unique.
The steps I followed to make this:
1rst step: I logged in to EasyEda to make this project 
2nd step: I then started with my first project after clicking "new project" and naming it "Build Guild HYD"
3rd step: I then started by adding the chip, resistor, and other things as well, with the help of writing the names of the parts in the EasyEda library 
4rth step: I organized all the parts and added wires to them 
5th step: I converted the schematic to "PCB1"
6th step: I started routing all the wires to each component in the PCB circuit.
7th step: I added the logos of, JLCPCB, EasyEDA, xyz. and Hackclub 
8th step: I then added my design picture and converted it into a gerber file.
